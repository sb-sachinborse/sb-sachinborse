## 👨‍💻 About Me

I'm building my expertise in **DevOps Engineering, Cloud Infrastructure, Automation, and Cloud Security**, with a focus on designing reliable, scalable, and secure infrastructure.

I enjoy automating repetitive tasks, managing infrastructure as code, building CI/CD pipelines, deploying containerized applications, and implementing security throughout the software delivery lifecycle.

- ☁️ **Cloud Platforms:** Google Cloud Platform (GCP) 
- 🐧 **Operating Systems:** Linux administration and troubleshooting
- 📦 **Containers:** Docker and Kubernetes
- 🔄 **CI/CD:** Jenkins and automated deployment pipelines
- 🏗️ **Infrastructure as Code:** Terraform and Ansible
- 🔐 **Security:** IAM, least privilege, secrets management, vulnerability scanning, and DevSecOps
- 📊 **Observability:** Monitoring, centralized logging, metrics, and alerting
- 🎯 **Goal:** Build production-minded, secure, automated cloud infrastructure.

> Security is not an afterthought. It is part of every stage of the infrastructure and deployment lifecycle.

```text
Developer Commit
      |
      v
Git / GitHub
      |
      v
Jenkins CI/CD
      |
      +----> Secret & Dependency Scanning
      |
      +----> Static Analysis / SAST
      |
      +----> Terraform Security Scan
      |
      v
Docker Image Build
      |
      +----> Trivy Image Scan
      |
      v
Container Registry
      |
      v
Kubernetes / GKE / EKS
      |
      +----> RBAC & Network Policies
      |
      v
Monitoring + Centralized Logs
```
